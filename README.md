
# Google Stock Price Prediction

A Machine Learning and Deep Learning project to analyze stock market data and predict stock prices using Python and Streamlit.

## Project Overview

This project analyzes historical stock market data and predicts the next trading day's stock price using machine learning and deep learning models.

## Features

- Stock price prediction
- Historical stock market analysis
- Interactive dashboard
- Multiple company comparison
- Model performance comparison
- Data visualization

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / Keras
- Streamlit
- Plotly
- Yahoo Finance

## Installation

```bash
git clone https://github.com/gundlapallidivya/Google-Stock-Price-Prediction.git
cd Google-Stock-Price-Prediction
pip install -r requirements.txt
```

## Run the Application

```bash
python -m streamlit run stock_app.py
```

## Machine Learning Models

- Naive Baseline
- Linear Regression
- Random Forest
- LSTM

## Data Source

Historical stock market data is retrieved using Yahoo Finance (yfinance).
